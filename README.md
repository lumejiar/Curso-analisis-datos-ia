## 🚀 Cómo trabajar y entregar tus ejercicios

1. **Haz un fork de este repositorio** a tu cuenta de GitHub (solo la primera vez).
2. Abre el notebook del módulo correspondiente en Colab usando el botón **Open in Colab** de la tabla de arriba (asegúrate de abrirlo desde tu fork).
3. Trabaja en el notebook y guárdalo en tu fork: **Archivo → Guardar una copia en GitHub**, en la ruta:modulo-XX-nombre/Entregas/Nombre_Apellido.ipynb
4. Crea un **Pull Request** desde tu fork hacia este repositorio.
5. El profesor revisará tu Pull Request, dejará comentarios, observaciones y la calificación directamente ahí.

Para instrucciones detalladas paso a paso, consulta el `README.md` de cada módulo.
